# DATA 612 – Recommender Systems  
**Author:** Sheriann McLarty  
**Program:** MS in Data Science  
**Institution:** CUNY School of Professional Studies  

## About This Repository

This repository contains course materials, assignments, and project work for DATA 612: Recommender Systems. The course explores the foundations and applications of recommendation algorithms used across industries — from e-commerce to streaming platforms.

Work includes both individual assignments and team-based exercises, with a focus on:

- **Content-Based Filtering**
- **Collaborative Filtering**
- **Hybrid Recommender Systems**
- **Non-Personalized Techniques**
- **Sentiment-Based Recommendations**
- **Attack Detection and Mitigation**
- **System Evaluation and Tuning**

## Tools & Technologies

- **R** and **RMarkdown** for analysis and reporting  
- **Python** (via `reticulate`) for modeling and data manipulation  
- **Seaborn / Matplotlib** for visualizations  
- **Git / GitHub** for version control and collaboration  

## Structure

- `*.Rmd`: RMarkdown notebooks with embedded code, analysis, and written responses
- `*.html`: Rendered documents for submission or sharing
- Additional files: CSVs, code snippets, and utility scripts as needed

## How to Use

Clone the repository or download individual `.Rmd` files to explore implementations.  
If using `reticulate`, make sure Python is properly configured in your R environment.
